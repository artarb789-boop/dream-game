# Первое убежище · прототип 0.1

Одиночное пошаговое выживание на окраине посёлка. Вы начинаете в доме с разбитым окном. Пока вы осматриваете карту и выбираете действие, мир ждёт.

## Запуск на Windows

Распакуйте игровой архив и откройте FirstShelter.exe. Движок и данные игры встроены в исполняемый файл. Сборка предназначена для Windows x86-64 с поддержкой OpenGL 3.3.

## Управление

- WASD или стрелки — шаг. Шаг в закрытую дверь открывает её, шаг на соседнего мертвеца наносит удар.
- Левый щелчок — осмотр клетки. Подойдите к предмету на соседнюю клетку по горизонтали или вертикали и выберите действие справа.
- E — переключаться между доступными объектами рядом. Пробел — ждать минуту.
- F5 — сохранить. F9 — загрузить. Запись хранится в каталоге пользовательских данных Godot, отдельно от игры.

## Первый вечер

Для начала осмотрите кухонный шкаф. В нём есть котелок. Снаружи под окном стоит бочка. Южнее дома под навесом лежат сухие дрова. В печи можно прокипятить воду. За инструментом для ремонта окна отправляйтесь через дорогу. Порядок работ выбираете вы. После подготовки убежища можно продолжать исследование.

Карта фиксирована. В прототипе есть простые противники, дождь и прояснения, обогрев, разбор стула, ремонт, кипячение воды и отдых. Числа и графика служат для первой проверки.

## Проект и проверка

Откройте project.godot в Godot 4.4.1 и запустите главную сцену. Правила находятся в world.gd, карта и интерфейс отрисовываются в main.gd.

Из каталога проекта:

    godot --headless --script test_day.gd
    godot --headless --export-release "Windows Desktop" /путь/FirstShelter.exe

Для экспорта нужны шаблоны Godot той же версии. Тест проходит эпизод с действующими противниками, проверяет расход материалов и продолжение после загрузки.
